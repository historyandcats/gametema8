# Гонец: первые Романовы

Учебная игра проекта «История и котики» по скрипту «Первые Романовы» (1613–1682).

- 6 миссий по 6 заданий + финал, 5 жизней на весь путь.
- Всё в одном файле `index.html`: без сборки, без зависимостей, работает офлайн.

## Как опубликовать на GitHub Pages
1. Создайте репозиторий (например, `romanovy`) в аккаунте `historyandcats`.
2. Загрузите `index.html` и `README.md` в корень (Add file → Upload files).
3. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
4. Через минуту игра откроется по адресу `https://historyandcats.github.io/romanovy/`.
